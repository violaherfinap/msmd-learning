# Mermaid diagrams for baseline slides

Palette: navy `#0B1F3A`, pink `#E85D9E`, white `#FFFFFF`, black `#111111`.

| File | Slide |
|---|---|
| `slide1_dorfer.mmd` | 1 — Dorfer (paper) |
| `slide2_dorfer_full.mmd` | 2 — Dorfer Task 1 + Task 2, full slide |
| `slide3_task1_vertical.mmd` | 3 — Task 1, right panel |
| `slide4_task2_vertical.mmd` | 4 — Task 2, right panel |

Render at [mermaid.live](https://mermaid.live) or:

```powershell
npx @mermaid-js/mermaid-cli -i slide3_task1_vertical.mmd -o slide3.png -b white -w 2400
```

Slides 1/3/4: about 6.2 × 6.0 in. Slide 2: about 12.5 × 6.2 in. Tidak ada
komponen frozen; panah putus-putus hanya berarti inisialisasi bobot.
